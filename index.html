WMSO（世界モデル型スキル統括）は、未来の微細な行動列を毎回解き直すのではなく、 次に使うスキル、その開始状態、ハンドオフ条件、失敗時の回復を世界モデルで予測し、統括する研究アーキテクチャです。

01 / Core idea

逐次行動列から、準備・解放型の制御へ。

一般的な軌道最適化では、世界モデル内で複数ステップ先の行動を並べ、実行のたびに更新します。 WMSOでは計画単位をスキルへ引き上げ、世界モデルは「何を」「どの状態から」「どの条件で」開始するかを評価します。

Sequential action planning

未来の微細な行動を、毎ステップ並べ直す。

aₜ aₜ₊₁ aₜ₊₂ …

高次元の長期計画になりやすく、外乱や目標変更で予定列が陳腐化します。実行時の再計画は必要ですが、すべてを微細行動で表すと探索範囲が急増します。

02 / Architecture

準備、判定、解放、実行、ハンドオフ。

WMSOは、未確定な内部計画と、ロボットが実際に読む実行状態を分離します。 準備中は現在のスキルまたはホールド制御を継続し、条件が揃った時だけ次スキルをコミットします。

skill-level closed-loop orchestration belief → preparation → commit → execution → handoff / recovery
01

準備

出力ヌル準備領域で、次スキルに必要な開始条件を探索します。

  • 候補スキルとパラメータ
  • 望ましいハンドオフ状態
  • 成功確率と不確実性
  • bridge / recovery候補
02

コミット判定

実行前に契約条件を検証します。満たさない場合は現制御を維持して再準備します。

  • 開始集合への所属
  • ハンドオフ互換性
  • 不確実性が許容範囲内
  • 安全・実行束・版の整合
03

解放

準備済み情報を、実行器が読める確定済みの実行束へ変換します。

  • スキルIDを確定
  • 初期状態・目標を確定
  • 制御器と監視条件を結合
  • 原子的に切り替え
04

閉ループ実行

学習済みスキルダイナミクスを、観測フィードバックで補正しながら展開します。

  • 外乱に応じて局所補正
  • 成功・失敗・進捗を監視
  • 安全制約を常時適用
  • 必要時は停止・回復へ
05

ハンドオフ

終了状態を次スキルへ渡します。直接つながらない場合はbridgeまたはrecoveryを選びます。

  • 終了集合を判定
  • 次スキルへ状態を受け渡し
  • no-chainを明示
  • 次の準備サイクルへ
準備中現行スキル、ホールド、インピーダンス制御などが物理系を継続して安定化します。
実行中世界モデルは結果予測を更新し、次の準備を並行して進められます。
異常時不確実性超過、契約不一致、失敗兆候ではfail-closedで解放を禁止します。

「出力ヌル」は、候補計画がどれだけ内部で変化しても、コミット前はアクチュエータ指令へ直接影響しない構造を意味します。 神経科学上のヌル空間をそのまま複製するのではなく、ソフトウェア境界として再定式化しています。

Pre-commit output isolation

∂at / ∂pprep = 0

コミット前の準備状態 pprep を更新しても、現在の実行行動 at は変化しない。 これは罰則で近似するのではなく、実行器が未確定状態を読まない構造で保証します。

03 / Safety boundary

安全は「うまく学習すること」だけに依存させない。

世界モデルと方策は誤る可能性があります。そこで、候補生成・契約検証・実行コミットを別の段階に分け、未確定な推論が制御出力へ漏れないようにします。

  • コミット前は実行束を不変に保つ
  • 不確実性・no-chain・failureを明示的に予測する
  • 互換性または安全条件の不成立時は切り替えない
  • 実行時は観測帰還と低レベル安全制御を維持する

04 / What the model predicts

世界モデルが予測するのは、次の一手だけではない。

スキル単位の半マルコフ決定過程として、開始から終了までの結果、所要時間、失敗様式、接続可能性を予測します。 これにより、長期課題を微細な制御周期より短い意思決定列へ圧縮します。

01 / OUTCOME

スキル結果

終了時の信念状態、物体配置、接触・把持・張力など。

02 / TIME & COST

時間とコスト

継続時間、エネルギー、切替コスト、変更コスト。

03 / FAILURE

失敗とno-chain

失敗モード、次へ接続不能な状態、回復の必要性。

04 / UNCERTAINTY

不確実性

予測の信頼度、分布外状態、観測不足、モデル間不一致。

05 / HANDOFF

ハンドオフ

次スキルの開始集合との互換性と、bridge候補。

05 / Robotics stack

WMSOは、世界理解と物理制御の間をつなぐ。

上位のタスク分解から制約を受け取り、実行可能なスキルへ変換します。下位では、学習済み方策、残差強化学習、ヒューリスティック、安全制御が閉ループで物理系を動かします。

    知覚・目標・タスク分解

    視覚と言語から状況を推定し、目的、制約、候補サブタスクを生成します。

  2. W

    世界モデル内でスキル結果を想像し、選択、準備、遷移、回復を統括します。

  3. L2

    学習済み閉ループスキル

    模倣学習や強化学習で獲得したスキルを、観測帰還で補正しながら実行します。

  4. L1

    ヒューリスティック・安全制御

    接触維持、力制限、停止、ホールドなど、決定論的な制御境界を担います。

06 / Conceptual origin

神経科学の幾何学を、工学的な実行境界へ。

着想の源泉は、運動準備が出力ヌル空間に保持され、開始合図後に再帰ダイナミクスが出力有効方向へ展開するという運動皮質の説明です。 WMSOは、この説明をモデルベース強化学習とスキル統括へ移した研究提案であり、生物学的機構をそのまま再現するものではありません。
