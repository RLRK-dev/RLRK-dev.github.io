01Our purpose

Robots people can
entrust with a role.

Real environments never stay exactly the same. As objects and conditions change, robots need to perceive the situation, make decisions and act steadily while managing risk.

We represent situations through visual observations and language, and learn motion from human demonstrations and environmental feedback. We then connect learned skills to the current situation, pursuing systems that adapt to change.

Perceive the situation

Understand the state of objects and the task through images and language.

Learn the motion

Start with human demonstrations, then improve through environmental feedback.

Connect the work

02Our technical approach

Perceive. Learn.
Connect to action.

Bringing complementary methods together for robots that work in the real world.

01
Vision–language–action (VLA)

Connect what is seen
with what is asked.

We capture objects, poses, movement and relationships from visual observations, integrating language instructions and task context into a shared representation. This understanding informs action selection and skill connections.

02
Imitation learning

Build a foundation
from human experience.

We acquire an initial policy—a rule for choosing actions—from the movements and decisions in demonstration data. Human experience provides the starting point for robot behavior.

03
Reinforcement learning

Refine motion
through experience.

We optimize policies using rewards and environmental feedback, improving adaptation to conditions that differ from those encountered during training.

03WMSO

Connect skills
to the situation.

How should learned behaviors be selected and handed over? A world model anticipates state changes while the system prepares a suitable starting state for the next skill.

WMSO: World-Model-Based Skill Orchestration
World-model-based skill selection, transitions and recovery.

  1. 01

    Understand the current state

    Use observations to select the next skill.

  2. 02

    Prepare execution

    Prepare a starting state suited to the selected skill.

  3. 03

    Check the conditions

    Check that the conditions for beginning the motion are satisfied.

  4. 04

    Run the skill

    Start motion generation using the learned skill.

Reassess the situation during execution to inform selection, transitions and recovery.

Read more about WMSO

WMSO treats skills learned through reinforcement and imitation learning as higher-level choices. Rather than planning every low-level action in sequence, it safely prepares a suitable initial state for the next skill and begins learned motion generation when the conditions are met. It integrates skill selection, transitions and recovery while reassessing the situation during execution, aiming for responsive skill changes.
